Sales Data Analysis Dashboard

Project Overview

This project focuses on analyzing sales data to understand business performance, sales trends, and profitability. Python, Pandas, Excel, and Power BI are used to clean, analyze, and visualize the data through an interactive dashboard.

Tools & Technologies

Python

Pandas

Microsoft Excel

Power BI

Project Workflow

Identified missing values and duplicate records.

Cleaned and formatted sales data using Python and Pandas.

Checked invalid sales values and validated profit calculations.

Performed sales and profit analysis.

Created an interactive Power BI dashboard to visualize business performance.

Dashboard Features

Total Sales and Total Profit

Total Orders and Quantity

Profit Margin

Monthly Sales Trends

Sales by Category

Sales by Product

Sales by Region
